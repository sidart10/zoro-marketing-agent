# Zoro Marketing Agent

Zoro is a private, local-first marketing and creative-production agent. Give it a product, an
audience, and an objective; it helps turn that brief into grounded messaging, written content,
images, video, and voiceover while keeping the creative direction consistent.

> **Status:** private and incubating. This repository is being developed for personal use before
> any broader release.

## What Zoro does

- Analyzes product URLs and photos before making creative claims.
- Builds one campaign brief around the audience, objective, promise, evidence, deliverables, brand
  constraints, distribution context, and success measure.
- Writes social content, articles, newsletters, ad copy, and video scripts.
- Generates or edits campaign imagery using product and character references.
- Generates video clips, voiceovers, and stitched final assets.
- Reviews work as a creative director: one strongest recommendation, clear tradeoffs, and honest
  evidence rather than generic AI polish.

## How the workflow fits together

```text
Brief
  -> product and audience truth
  -> campaign direction and script
  -> reference images and storyboards
  -> video and voice generation
  -> edit, stitch, review, and delivery
```

Zoro preserves the same brief, product facts, visual anchors, approved copy, and technical
constraints across each phase instead of treating every output as an unrelated generation.

## Guardrails

- **Paid generation requires approval.** Zoro runs a free `dry_run`, shows the provider, model,
  batch, important parameters, and estimated cost, then waits for explicit approval.
- **Drafting is not publishing.** Zoro does not post, schedule, send, launch, or release anything
  without approval of the final artifact, destination, and action.
- **Private work stays private.** Credentials never belong in Git, and campaign materials belong in
  the ignored `workspace/` area rather than the repository.
- **Pending jobs are rejoined.** Long-running generations are checked with `job_status`; they are not
  resubmitted and billed twice.

## Local setup

Prerequisites: Node.js 18+ and Python 3. The runtime uses only the Python standard library.

```bash
git clone https://github.com/sidart10/zoro-marketing-agent.git
cd zoro-marketing-agent

node bin/install.js --codex     # OpenAI Codex
node bin/install.js --claude    # Claude Code
node bin/install.js --all       # every detected host
```

The existing runtime keeps its internal package, MCP, environment-variable, and filesystem names
for compatibility. That includes the credential file at `~/.supercmo/.env` and the MCP registration
name `supercmo`; these are implementation details, not the repository identity.

Add only the provider keys you need:

```bash
# ~/.supercmo/.env
FAL_KEY=                  # image and video generation
ELEVENLABS_API_KEY=       # voiceover
GEMINI_API_KEY=           # image and video analysis
FIRECRAWL_API_KEY=        # product-page extraction
```

Restart the host after changing keys, then use the `setup_status` tool to verify available
capabilities.

### Fully local telemetry setting

The retained runtime contains an anonymous telemetry client for compatibility with its original
distribution. Disable it for this private agent:

```bash
export SUPERCMO_TELEMETRY=false
```

See [TELEMETRY.md](TELEMETRY.md) for the exact retained behavior and all opt-out methods.
